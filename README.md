# 🌿 छाया AI (Chaya AI) - Smart Agricultural AI Advisor

**छाया AI** हे महाराष्ट्रातील (नांदेड व मराठवाडा) शेतकऱ्यांसाठी तयार केलेले प्रगत कृषी सल्लागार व्यासपीठ आहे. हे व्यासपीठ शेतकऱ्यांचे इनपुट (तालुका, माती प्रकार, पाणी, हंगाम, जमीन क्षेत्रफळ व प्रश्न) समजून घेते आणि **पूर्व-साठवलेल्या कृषी फाइल्स (Knowledge Base)** व **Groq AI** चा वापर करून वैयक्तिकृत पीक शिफारसी, खत नियोजन, नफा-तोटा अंदाज आणि थेट APMC बाजारभाव सादर करते.

---

## 🌟 प्रमुख वैशिष्ट्ये (Key Features)

1. **🧠 AI Knowledge Retrieval (RAG)**:
   - शेतकरी इनपुटनुसार पूर्व-साठवलेल्या फाइल्समधून (`data/` फोल्डर) संबंधित पिके, माती गुणधर्म (pH, नत्र, स्फुरद, पालाश), खत वेळापत्रक आणि रोग निदान शोधून अचूक सल्ला तयार केला जातो.

2. **⚡ दुहेरी कार्यपद्धती (Dual AI Mode)**:
   - **Groq AI Mode**: API Key टाकल्यास थेट Groq (openai/gpt-oss-120b मॉडेल) द्वारे अस्खलित मराठीत संवादात्मक सखोल विश्लेषण.
   - **Offline Smart Knowledge Engine**: इंटरनेट किंवा API Key नसतानाही इनबिल्ट कृषी मॅट्रिक्स व अल्गोरिदमद्वारे 100% कार्यक्षम.

3. **🎤 मराठी व्हॉइस इनपुट (Voice-to-Text)**:
   - शेतकरी थेट मराठीत बोलून आपला प्रश्न किंवा पिकाची समस्या विचारू शकतात.

4. **💬 छाया AI थेट संवाद (Live Chatbot Widget)**:
   - स्क्रीनवर सतत उपलब्ध असणारा संवाद सहाय्यक, ज्यावर शेतकरी कोणत्याही किडीचे किंवा खताचे नाव विचारून त्वरित उत्तर मिळवू शकतात.

5. **💰 एकरनिहाय नफा व उत्पादन कॅल्क्युलेटर**:
   - शेतकऱ्याच्या दिलेल्या एकर क्षेत्रफळानुसार एकूण अंदाजे उत्पादन (क्विंटल/टन), उत्पादन खर्च आणि निव्वळ नफ्याचे अचूक गणित.

6. **📊 APMC चालू बाजारभाव आलेख (Chart.js)**:
   - नांदेड, अर्धापूर, भोकर आणि परिसरातील मोंढ्यांमधील चालू सरासरी व कमाल बाजारभावांचा थेट आलेख.

## 📁 फाइल्सची रचना (Project Structure)

```
chaya-ai/
│
├── index.html                   # मुख्य शेतकरी इनपुट पोर्टल (Voice mic, Taluka, Soil selector)
├── result.html                  # AI शिफारस अहवाल, ROI कॅल्क्युलेटर, APMC चार्ट व ड्रॉवर्स
├── server.py                    # स्थानिक डेव्हलपमेंट वेब सर्व्हर (python server.py)
│
├── js/
│   ├── ai-engine.js             # Knowledge Retrieval, Groq AI Connector & Smart Evaluator
│   └── chat-assistant.js        # फ्लोटिंग AI संवाद चॅटबॉट (Marathi Voice & Text)
│
└── data/                        # 📂 पूर्व-साठवलेल्या कृषी फाइल्स (Knowledge Base)
    ├── crops_database.json      # पिकांची माहिती, खते, कालावधी व उत्पादन
    ├── soil_and_climate.json    # तालुकावार माती विश्लेषण, pH व पाण्याचे स्तर
    ├── fertilizers_and_schemes.json # खत नियोजन, जीवामृत व शासकीय योजना (PM-Kisan, Mahadbt)
    ├── market_prices.json       # APMC चालू बाजारभाव व तेजी-मंदी अंदाज
    └── pests_and_diseases.json  # रोग व कीड निवारण मार्गदर्शक (सेंद्रिय + रासायनिक)
```

## 🚀 कसे चालवायचे? (How to Run)

### पद्धत 1: Python Server द्वारे (शिफारस केलेली)
कमांड प्रॉम्प्ट किंवा पॉवरशेल उघडून खालील कमांड चालवा:
```bash
cd "C:\Users\shelk\.gemini\antigravity\scratch\chaya-ai"
python server.py
```
हे आपोआप तुमच्या ब्राउझरमध्ये `http://localhost:8000` उघडेल.

### पद्धत 2: थेट फाईल उघडून (Direct Browser)
- `index.html` फाईलवर डबल-क्लिक करून थेट ब्राउझरमध्ये उघडा.
- इनबिल्ट फॉलबॅक इंजिनमुळे थेट `file:///` मोडमध्येही सर्व शिफारसी सुरळीत चालतात.

## ✏️ स्वतःचा कृषी डेटा कसा जोडायचा? (How to Add/Edit Knowledge Files)

आपण `data/` फोल्डरमधील कोणत्याही JSON फाईलमध्ये नवीन पिके किंवा माहिती जोडू शकता:
- **नवीन पीक जोडण्यासाठी**: `data/crops_database.json` फाईल उघडा आणि नवीन पिकाचा ब्लॉक जोडा.
- **नवीन तालुका जोडण्यासाठी**: `data/soil_and_climate.json` मध्ये नवीन तालुक्याचे नाव व मातीचा प्रकार जोडा.
- **नवीन रोग उपाय जोडण्यासाठी**: `data/pests_and_diseases.json` मध्ये माहिती जोडा.
